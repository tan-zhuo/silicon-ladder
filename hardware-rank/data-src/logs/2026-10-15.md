## 一、`nvidia-rtx-5090-d`：26734 → 44464（SKU 死结解开）

### 先解 SKU —— 答案在库内自己身上

10-14 把这条的结转动作写成「不是去找 5090 D 的新报价，而是先确认库内这条到底指 D 还是 D V2」。方向对了，但**没必要去外部找——库内字段自己就写着答案**：

```
nvidia-rtx-5090-d:  vram_gb: 32,  bus_bit: 512,  release: 2025-01
```

5090 D V2 是 **24GB / 384-bit / 2025 年中**的二代特供卡。库内这条是 **32GB / 512-bit / 2025-01**，所以它**无歧义地指初代 RTX 5090 D**，不是 V2。

这一点被今天的南方都市报（10-15）从外部独立确认，该文专门把两者分开写：

> 5090显卡搭载32G容量的GDDR7显存，而5090D v2显卡使用24 GB容量的GDDR7。

**教训：SKU 同一性问题应当先查库内规格字段，再去外部找报价。** 10-14 把顺序搞反了，白等了一轮。

## 二、更正 10-14 的三处「查无来源」判断

10-14 用「库内这个数字在既往日志里查无来源」作为换值的理由，对三个数字都这么写过。今天在 smzdm `am934d7k`（10-09）里**一次找到了全部三个的出处，全部是显卡日报**：

| 库内曾有/现有值 | 10-14 的判断 | 实际出处 |
| --- | --- | --- |
| `nvidia-rtx-5070-ti` = 9394 | 「任何日志里都找不到来源」 | **显卡日报 9-30：5070Ti 涨至 9394** |
| `nvidia-rtx-5080` = 12499 | 「库内这个数字查无来源」 | **显卡日报 9-29：5080 涨至 12499，刷新历史最高** |
| `nvidia-rtx-5060-ti-8gb` = 3499 | 被当作三源打架的一方，来源不明 | **显卡日报 9-29：5060Ti 8G 涨至 3499，刷新历史最高** |

**这把 5070 Ti 的曲线形状改了，而且直接影响观察窗口的读法。** 10-14 写的是「8800(9-21) → 9100(10-08~10)，方向是**涨**的」。补上 9-30 这一点后，真实形状是：

```
8800 (9-21)  →  9394 (9-30，阶段高点)  →  9100 (10-08~10)
```

**不是单边上行，是冲高后回落。** 同理 5080：12499(9-29 高点) → 12100(10-08~10)，也是回落而非横盘。10-14 写的「12000–12100 横跨双 11 两侧，说明这个价位不是促销造出来的」结论仍然成立，但要补一句：**它是从 9-29 的 12499 回落下来的**。

**方法论更正：「库内数字查无来源」这个判断，在翻检范围只限于既往日志时不成立。** 既往日志只记录当轮取值，不记录上线时的初始值出处。以后这类话要写成「既往日志未记录其出处」，不能写成「无来源」——今天证明这两者差别很大。


## 新增方法论（本轮五条）

- **SKU 同一性问题，先查库内规格字段，再去外部找报价。** 5090 D 的死结挂了三轮，答案一直写在库内的 `vram_gb: 32 / bus_bit: 512` 里。10-14 把顺序搞反（先去外部找价），白等一轮。**顺序是：库内规格 → 确定 SKU → 再按 SKU 找同层报价。**
- **「库内数字查无来源」这个判断不成立，只能写「既往日志未记录其出处」。** 既往日志只记当轮取值，不记上线初始值的出处。本轮一次找回三个被判「无来源」的数字，全部出自显卡日报，且其中一个（9394）**补上后把曲线形状从「单边上涨」改成了「冲高回落」**，直接改变观察窗口的读法。
- **层级打架时，优先确认库内口径**属于**哪一层**，而不是在打架的数字里挑。 内存今天三层并存：颗粒现货 +8%、原厂创新高、**零售成品滞涨**。库内口径是零售层，所以 10-14 的「方向性偏低」在库内口径上不成立。**若上一轮凭「方向」抬价，今天就会撞上滞涨。方向性结论永远不能替代同层数字。**
- **「改了不动榜」有三种成因，必须分清**：① 不进排序（10-13 固态）；② 进排序但幅度不够（10-14 的 5070Ti/5080）；③ **进排序、幅度极大、但条目已在端点无可再降（本轮 5090 D，#37/37）**。三者对「要不要继续追这条」的含义完全不同。
- **内容农场改写站的识别判据：正文被插入乱序字符。** 如「价：50 ... 0Ti 16G涨至近4000元！」「系显RTX 50系列」。此类站即使转述真实一手源，**文本已被破坏到无法取值，一律丢弃，连「线索层」都不进**——这与 `hutaodewang` 那类「模板回收站」不同：后者文本完整、数据造假（可分段采信），前者文本本身已不可读。新增 `gigabytedevelopersinc.com`、`reuterd.com`、`dingeting.com`。
