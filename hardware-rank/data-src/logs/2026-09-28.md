## 一、今天唯一被证伪的东西（重要）

**影驰 RTX 5070 FIRE「4599 元」是旧闻重发，不是新报价。**

09-26 快科技 / 游民星空 / 凤凰网同步发了「影驰 RTX 5070 FIRE 显卡近日已正式开售……参考售价 4599 元」。这条如果成立，会直接推翻库内 `nvidia-rtx-5070 = 6949`（差 34%），所以必须裁决。

回溯结果：这张卡的首发是 **2025-03-05**（IT之家《影驰推出全新"赛博黑焰"设计 FIRE 系列显卡，RTX 5070 首发》），IT之家评测与图赏、腾讯新闻评测均为 2025-03 发布。4599 元是**2025 年 3 月的首发价**。pconline 产品页那个「参考报价 ￥4599」是长期未更新的厂商参考价页，不是在售成交价。

判定：**旧闻被 2026-09-26 重新推送**，属信源污染。库内 6949（09-20 日报刷新历史最高价）不动。

同一 pconline 页面上的「影驰 RTX 5090 D v2 星曜 LUNA OC 24G ￥17999」同理不可用 —— 库内 `nvidia-rtx-5090-d = 26734` 来自 09-16 日报实际报价，两者差 48%，厂商参考价页明显滞后。

**结转教训**：「近日已正式开售」这种没有具体日期的表述，配上厂商参考价页，是这轮行情里最容易踩的坑 —— 涨价期内所有停更的参考价页都会显得像"抄底价"。落盘前必须回溯首发日期。

## 三、为什么今天不 bump `meta.version`

`meta.json` 的 `updated` / `version` 语义是"数据更新到哪一天、第几版"。数据一条没动却把 `updated` 改成 09-28、`version` 改成 5，等于对外宣称"今天核过一遍价格且有变化"，是**假信号**。按手册「无变动不产生空提交」的同一条精神，`meta` 也不动。

本日志单独提交（`docs:` 而非 `data:`），与数据提交区分开。
